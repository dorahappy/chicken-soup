UI Visual Draft v0.1

吃饭了

视觉方向围绕饭点前的低决策成本、厨房协作和进度透明展开。客户侧以“今天吃什么”和“什么时候吃”为核心，厨师侧以“新订单、缺什么、做到哪了”为核心。

饭点感 使用番茄红、青蔬绿、米饭暖白构建食物联想，但控制饱和度，避免外卖平台的强促销感。
双角色 客户侧更轻、更像点餐；厨师侧更密集、更像工作台，保证处理订单时扫描效率。
状态优先 用状态条、看板和提醒块突出“现在做到哪了”，减少客户催问和厨师解释成本。
移动优先 首屏聚焦今日菜单，关键操作放在拇指区；桌面端扩展为厨房看板和菜单维护后台。
