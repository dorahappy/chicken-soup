UI Visual Draft v0.2

吃饭了

这版改成更有家庭厨房质感的方向：浅木纹、餐桌暖光和更重的任务层级。客户侧更像饭点点菜，厨师侧更像厨房台面上的待办工作台。

厨房感 新增木质台面、暖光和食材色块，让页面从通用管理工具转向“家里准备开饭”的场景。
双角色 客户侧保留轻量点餐感；厨师侧提高信息密度和任务优先级，方便快速处理新订单。
状态优先 状态条、看板和提醒块继续前置，颜色更沉稳，避免视觉上像外卖促销页。
可落地 仍然使用纯 HTML/CSS 和稳定组件形态，后续可以直接迁移到现有 Web MVP。
